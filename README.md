# Just Blog

A responsive, lightweight personal blog landing page built with custom HTML and CSS, packaged with Docker, and deployed using GitHub Pages.

You can view the live, running website here:
👉 **[View Live Blog Project](https://abigailnwizu-ux.github.io/just_blog/)**

* **Frontend:** HTML5, CSS3
* **DevOps / Deployment:** Docker, GitHub Actions, GitHub Pages
